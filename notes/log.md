# Notes Log

ノートの追加・更新・昇格の時系列記録。`grep "^## \[" log.md` で一覧取得可能。

新しいエントリは**冒頭に**追加する（新しい順）。形式は次のとおり。

```
## [YYYY-MM-DD] <種別> | <概要>
- <ファイル名>: <何をしたか>
```

種別は `ingest`（新規追加）/ `update`（更新）/ `verified`（昇格）/ `structure`（構成変更）/ `lint`（点検）を使う。
