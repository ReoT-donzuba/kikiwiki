# Humanize Text

生成AIの文章は、事実関係は正しくても独特の「型」があるせいで人間には読みにくく感じられる。
このスキルは、その型を検出して自然な文章に書き直すためのチェックリストと手順を提供する。

## 検出すべき「AIっぽさ」のパターン

1. **定型的な前置き・結び**
   「以下の通りです」「〜についてご説明します」「いかがでしたでしょうか」「まとめると」など、
   本題に情報を足さない枕詞・締めの言葉。→ 削除するか、本題に直接入る。

2. **過剰な箇条書き化**
   本来は2〜3文の地の文で自然に書ける内容を、無理に箇条書きへ分解している。
   → 論理的に列挙が必要な場合のみ箇条書きにし、それ以外は文章に戻す。

3. **機械的な接続詞・ナンバリングの多用**
   「まず」「次に」「そして」「最後に」を全段落で律儀に使う、
   または内容の関連が薄いのに「①②③」を振る。
   → 接続詞は文脈上必要な箇所だけに絞る。

4. **冗長なヘッジ表現の連発**
   「〜することができます」「〜と言えるでしょう」「〜かもしれません」「〜と考えられます」を多用し、
   言い切れる内容までぼかしている。→ 断定できることは断定する。

5. **不自然な並列構造**
   同じ文型・同じ文長の文が3つ以上連続する（AI特有の「きれいすぎるリズム」）。
   → 文の長さ・構造にばらつきを持たせる。

6. **中身のない強調・持ち上げ表現**
   「非常に重要です」「ぜひご検討ください」「素晴らしい成果です」など、
   具体性を伴わない評価・煽り文句。→ 削除するか、具体的な根拠に置き換える。

7. **見出し・記号の過剰装飾**
   絵文字の多用、太字の乱用、意味なく増える見出しレベル。
   → このリポジトリでは特に、指示がない限り絵文字・過剰な太字は使わない。

8. **具体性の欠如**
   抽象的な形容詞（「効果的」「重要」「様々な」）の羅列で終わり、
   固有名詞・数字・具体例が出てこない。→ 可能な限り一次情報の具体に戻す。

9. **質問形・煽り形で終わる結論**
   「いかがでしたか？」「試してみてはいかがでしょうか」で締める。
   → 結論は事実か次のアクションで終える。

## 適用手順

1. 対象テキストを通読し、上記1〜9のどれに該当するかを具体的な箇所ごとに洗い出す。
2. 事実関係・結論は変えずに、該当箇所を自然な表現へ書き直す。
3. 箇条書きを地の文に戻す場合、情報の欠落がないか確認する。
4. 書き直した箇所は簡潔に（何を・なぜ変えたか一言）報告する。長い前後比較は不要。

## 使用タイミング

- ノート草案（`notes/*.md`）を書いた直後のセルフレビュー
- ユーザーから「読みやすくして」「自然な文章にして」「AIっぽさを消して」と依頼されたとき
- 長文の生成AI出力を要約・転記する前の推敲
